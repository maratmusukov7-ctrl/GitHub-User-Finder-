# 🔍 GitHub User Finder

Поиск пользователей GitHub — GUI-приложение для поиска и сохранения избранных пользователей GitHub.

---

## 📋 Описание

Приложение позволяет:
- ✅ Искать пользователей GitHub по имени
- ✅ Просматривать информацию о пользователе (профиль, репозитории, подписчики)
- ✅ Добавлять пользователей в избранное
- ✅ Управлять списком избранных
- ✅ Сохранять избранное в JSON-файл
- ✅ Загружать избранное при запуске
